# Food Delivery System - Receipt Generator

## Purpose
This application is a backend receipt generator for a Food Delivery System. It collects customer information (name, food ordered, quantity, price, and delivery preference) and generates a formatted receipt with subtotal, service charge (5%), delivery charges, and grand total.

## Tech Stack
- Python 3.x
- Standard Python libraries (no external dependencies)

## How to Use
1. Ensure all three Python files (main.py, customer.py, receipt.py) are in the same directory (week_8)
2. Run the application:
   ```bash
   python main.py
